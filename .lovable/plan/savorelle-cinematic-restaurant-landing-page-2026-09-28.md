# Savorelle cinematic restaurant landing page

## Goal
Build the complete Savorelle one-page restaurant experience at `/`, closely following the uploaded reference’s dark editorial composition, section order, spacing, and orange-accented interaction style.

## What will be built
- A slim sticky navigation with anchor links, an order action, and a working mobile menu.
- A cinematic opening section using the supplied glazed-wings image, the exact “Savor Every Moment with Every Bite” headline treatment, reservation action, hand-drawn accent, and overlapping service highlights.
- The full reference-led page sequence:
  1. Culinary Artistry menu carousel
  2. Serving You Better layered staff/food composition
  3. Luxury Dining overlapping food collage
  4. Crafted by Experts chef carousel
  5. Patron testimonials
  6. Reservation image banner with validated form
  7. “Let Flavor Lead the Way” promotional banner
  8. Editorial footer
- Working anchor navigation, swipe/arrow carousels, order actions, reservation scrolling, mobile menu, and reservation validation/success feedback.
- Responsive recomposition for desktop, tablet, and mobile rather than simple shrinking.

## Images
- Use the supplied glazed-wings image for the opening visual.
- Use the supplied Truffle Pasta, Saffron Lobster, and Pistachio Fondant images as the three featured dishes, with the brief’s names/prices adapted where needed.
- Use the supplied wide pasta image for the final promotional banner.
- Generate a cohesive small set of missing visuals: a female restaurant server, three chef portraits, one overhead reservation scene, and supporting plated-food imagery for the editorial collages.
- Keep every generated image in the same black-studio, dramatic side-lighting campaign style; the uploaded screenshot remains reference-only.

## Visual system
- Translate the exact supplied dark/ivory/orange palette into semantic theme tokens.
- Use Cormorant Garamond for expressive editorial headings and a compact sans-serif for navigation, labels, and body text.
- Add restrained tactile grain, soft shadows, minimal borders, compact pill actions, and consistent rounded image corners.
- Use subtle entrance, scroll, image-scale, and hover motion with reduced-motion support.

## Technical details
- Implement modular React sections and reusable cards while keeping the page route concise.
- Add Motion for React for restrained reveals and interactive movement.
- Store supplied uploads through the project asset system and import their URL pointers.
- Add unique Savorelle title, description, Open Graph, and Twitter metadata to the home page.
- Verify the final experience in the live preview at desktop and mobile sizes, including navigation, carousel controls, menu actions, and reservation submission.
